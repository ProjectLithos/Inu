# Inu SDK 0.0.18 embedded in Kath

The embedded Inu SDK surface is version-aligned with Inu 0.0.18. The pinned compiler/runtime contract remains .NET SDK 10.0.302, NativeAOT/ILCompiler 10.0.10, and LLVM/Clang/LLD 22.1.6.

Kath 0.0.18 is distributed with Inu in one flat FullSource ZIP. The source package contains no nested repository/source ZIPs; the root build extracts the FullSource package and builds the expanded source directly.
