System.IO.Whole-file and directory I/O

Inu-owned .NET-compatible whole-file and basic directory API. Current working directory is process-local; spawned child processes inherit the parent working directory, and relative file/directory paths are resolved by the kernel against that process state before reaching the VFS. The current bootstrap starts root userland processes at the mounted VFS namespace root. Filesystem format, permissions and higher-level directory layout remain OS policy. Directory.CreateDirectory creates one directory level; Directory.Delete currently removes empty directories only. Enumeration remains deferred until the selected path-join policy is exposed directly. Initial user/kernel path transport is ASCII.
