# Kath 0.0.18

Kath 0.0.18 repairs the root FullSource bootstrap. `C:\DCLG\Build.bat` now builds either the newest discovered/explicit FullSource ZIP or, when that ZIP has already been extracted, the complete flat Inu + Kath source tree already present under `C:\DCLG`.

The release retains the Electron/Theia Kath implementation and the private Node.js 22.22.0 / Python 3.13.15 build toolchain provisioning.
